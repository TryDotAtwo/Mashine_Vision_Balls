# Проверка алгоритма по видео: 01.10.2026

Реализованы радиальная градиентная подгонка с `soft_l1`, субпиксельные максимумы, угловая опора, остаток и контроль эллиптичности. Обнаруженные Hough-кандидаты с непригодным результатом не выдаются как измерения. Уточняемые кандидаты и причины отказов хранятся в `python_quality_v1`; повторный экспорт восстанавливает `quality.json`. Первичное обнаружение по Хафу и семантическая принадлежность окружности физическому шарику остаются отдельными вопросами.

Основной пакетный CLI выбирает `radial`; старый `kasa` доступен для сравнения, прежнего режима одного объекта и отключённого уточнения. API-конфигурация сохраняет совместимое старое значение, новый метод задаётся явно. Трекер использует интервалы времени; прогноз без найденного края не является наблюдением. Исправленные временные метки учитываются в сводке. Два потока OpenCV ограничивают внутреннее распараллеливание CLI, не потоки всех библиотек/декодера.
