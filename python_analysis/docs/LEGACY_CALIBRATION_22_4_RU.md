# Уточнение по константе 22.4 мм в старых скриптах

## Где встречается

- `legacy/scripts/Машинное_зрение_Шарики.py`: `MainRadius = 22.4`, функция `calculateRadius(rSmall, rBig)`.
- Варианты копий: сравнение с фиксированным радиусом ~356 px для «большого» круга.

## Что делает формула

Используется отношение радиусов в пикселях:

`R_ball_mm = MainRadius * (r_small_px / r_big_px)`.

Следовательно, `MainRadius` имеет размерность **мм** и играет роль **физического радиуса опорного круга** (референса), которому соответствует `r_big_px` в кадре.

## Длина окружности или диаметр?

- **Длина окружности 22.4 мм:** `D = C/π ≈ 7.13 мм`. Тогда «большой» круг в кадре масштабировался бы к ~7 мм диаметра — для референса-ячейки это возможно только если ячейка очень узкая; при этом константа всё равно должна была бы задаваться как радиус/диаметр в мм, а не как длина окружности, иначе формула масштаба неверна.
- **Диаметр 22.4 мм:** физический радиус референса был бы **11.2 мм**, а в коде подставлено **22.4** — возможная систематическая ошибка **×2**, если автор имел в виду именно диаметр.
- **Радиус 22.4 мм:** диаметр опорной окружности **44.8 мм** — типичный порядок для визуально крупного кольца ячейки в кадре; согласуется с именем `MainRadius`.

## Рекомендуемая позиция для отчёта

1. Считать **22.4 мм радиусом опорной окружности в старой калибровке** до прямого измерения.
2. Подтвердить **штангенциркулем** внутренний/видимый диаметр ячейки в плоскости наблюдения.
3. В новом пайплайне задать масштаб явно: `--measurement-mode reference --reference-diameter-mm ... --reference-sigma-mm ...`, без магических чисел из GUI-экспериментов.

## Связь с текущим кодом

Текущий `src/mvb/pipeline.py` не использует 22.4: масштаб задаётся FOV или диаметром референса в мм из конфигурации.
