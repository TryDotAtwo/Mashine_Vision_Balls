# Проверенные этапы обработки, 01.10.2026

| Этап | Фактически выполненная проверка | Граница результата |
|---|---|---|
| Исходные данные | SHA-256 исходных видео; сохранение оригинальных файлов | Модель телефона заявлена исполнителем; не установлена по каждому файлу |
| Декодирование | Все 1395 кадров шести серий; 855 кадров обычной записи; доступный префикс старого архива; 715/1054 кадров экранных записей | Повреждённый архив прочитан только до 1960 из 4234 кадров |
| Яркостный канал и поиск | Цветное архивное видео, CLAHE, Хаф, профиль тёмного объекта, ROI и диапазон размеров | Промышленная камера уже монохромная; SDK захвата в пакетный анализ не встроен |
| Контур | Радиальные градиенты, субпиксельная подгонка soft_l1, угловая опора, остаток, эллиптичность, явные отказы | Пригодная окружность сама по себе не подтверждает физический шарик |
| Сопровождение | Прогноз по времени; пересечение, пропуски, нерегулярные интервалы; синтетические смены ID | Без ручной разметки ID не равен подтверждённой личности объекта |
| Калибровка | Отдельный виртуальный эталон; предварительная калибровка каждой телефонной серии | 3.98 мм приблизительно, неопределённость штангенциркуля неизвестна |
| Неопределённость | Тесты формул и NULL при отсутствии входной неопределённости | Абсолютная погрешность реального стенда не установлена |
| Хранение | 29 тестов, включая шесть интеграционных с ClickHouse; вставка протокола последней, счётчики строк и чтение обратно | Это не межтабличная транзакция |
| SQL и повторный экспорт | 24 побайтовых сравнения шести серий и восемь сравнений двух архивных запусков | Повторный экспорт изображений без исходного видео не выполняется |
| Графики и медиа | PNG/JPG, шесть полностью декодированных размеченных MP4; архивные MP4 855/392 кадров | Размеченный MP4 использует среднюю FPS, точное время хранится в таблице |
| Независимая синтетическая разметка | Seed 903/904, 480 кадров, TP/FP/FN/RMSE и смены ID | 48 деформированных объектов отвергнуты; дрейф масштаба не компенсируется |
| Документ | LaTeX, библиография, схемы SVG/PDF, постраничная визуальная проверка | Раздел 2 и аппаратная экспериментальная серия выполняются отдельно |

Нет оснований объявлять алгоритм идеальным или подтверждать заданную аппаратную точность по этим программным проверкам. Полная ручная разметка независимых реальных серий, подтверждённый эталон и запуск на стенде остаются необходимыми.
